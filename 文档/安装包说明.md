# 成长股分析套件 · 安装包说明

本文只说明 **Windows 安装包** `StockAnalysisSetup.exe`：它是什么、装到哪里、装完怎么开、数据在哪、如何卸载。功能和设计见 [产品说明](产品说明.md)、[功能介绍](功能介绍.md)。

安装包位置（构建完成后）：

`dist\installer\StockAnalysisSetup.exe`（约 120MB）

---

## 这是什么

这是一个 **Inno Setup 安装程序**，把已经打包好的桌面程序装到当前用户目录。安装后无需再装 Python，也无需管理员权限。

双击安装包即可；装完会得到：

- 主程序 `StockAnalysis.exe`（图形界面）
- 运行所需的 `_internal` 依赖
- 配置模板：`config.yaml`、`userdata\watchlist.txt`、`userdata\settings.yaml`
- 本目录一份 `使用说明.txt`

**不会**把开发机上已下载的招股书、财报、研报 PDF 打进安装包。那些文件体积很大，安装后由程序按需要自行下载到本机。

---

## 系统要求

| 项 | 说明 |
| --- | --- |
| 系统 | Windows 10 / 11，64 位 |
| 权限 | 当前用户即可，不必管理员 |
| 网络 | 筛选、下载、出图、日报需要访问国内公开站点（巨潮、东方财富、中国政府网等） |
| 磁盘 | 程序本身约一百多 MB；下载财报和研报后会再占数 GB，视自选股数量而定 |

部分电脑会把未签名的安装包标成「Windows 已保护你的电脑」。若你确认文件来自本项目，可在 SmartScreen 里选择仍要运行。杀毒软件偶发误报，可将安装目录加入排除项。

---

## 安装

1. 双击 `StockAnalysisSetup.exe`。
2. 按向导下一步。默认目录为：

   `%LOCALAPPDATA%\StockAnalysis`

   一般即 `C:\Users\<用户名>\AppData\Local\StockAnalysis`。可以改到别的文件夹，请选有写权限的位置。
3. 可选「创建桌面快捷方式」。勾选后，快捷方式指向图形界面，**不会**带上开机托盘参数。
4. 完成后可勾选「立即打开图形界面」。

开始菜单分组名是「成长股分析套件」。

升级安装时：已存在的 `config.yaml`、`userdata\watchlist.txt`、`userdata\settings.yaml` **不会被覆盖**，自选股和开关会保留。

---

## 装完以后

工作目录就是安装目录。程序读写的都是安装目录下的文件，而不是项目源码目录。

| 路径 | 用途 |
| --- | --- |
| `StockAnalysis.exe` | 双击打开统一界面（无黑色命令窗口） |
| `config.yaml` | 筛选门槛、点金术门槛、下载范围、限速 |
| `userdata\watchlist.txt` | 自选股名单（与机械筛选、点金术分开） |
| `userdata\settings.yaml` | 开机自启、每日日报、日报目录、日报时刻 |
| `userdata\source_preference.yaml` | 运行后自动生成：行情源顺序（默认腾讯优先、东财最后）。安装包不预置 |
| `data\` | 运行后生成：筛选结果、点金术、文档、政策库、技术面输出、日报副本 |
| `使用说明.txt` | 安装目录内的简短命令说明 |

命令行（在安装目录打开终端）：

```text
StockAnalysis.exe
StockAnalysis.exe --help
StockAnalysis.exe --daily-report
StockAnalysis.exe --daemon
```

`--daily-report` 不弹窗、不弹黑框，按 `settings.yaml` 生成日报（自选股章节 + 点金术全市场；总览会标出点金术里的自选股）。`--daemon` 只出现在右下角托盘：登录后自动挂上，需要时从托盘打开主界面；即使从不点开，到点仍会生成日报。界面「定时任务」页的开关会立刻写回 `settings.yaml`；每次启动都会重新读这份文件。新安装默认打开开机自启与每日更新。

日报默认写到桌面 `日报集\<日期>\`，可在 `settings.yaml` 的 `report_dir` 或界面里改。该日期目录下：`自选股\`（总表、技术面/基本面汇总、每只个股的综合分析与详报）、`点金术\`、`点金术extra\` 三个并列文件夹，日期根另有 `点金术技术信号汇总` 与 `点金术extra技术信号汇总`（md+csv）。命中且在自选股中的个股目录名为 `代码_名称_自选`。

## 卸载

用 Windows「应用和功能」或开始菜单里的卸载项即可。不需要管理员。

卸载会删除程序和缓存类文件（如 `data\cache`、托盘日志）。**已经下载的财报、研报、自选股名单**可能仍留在安装目录；若要彻底清掉，卸载后再手动删除 `%LOCALAPPDATA%\StockAnalysis`（或你改过的安装路径）。

若曾打开开机自启或每日日报，请先在界面「定时任务」里关掉对应开关，再卸载，以免留下失效的 Windows 计划任务（`StockAnalysisAutostart`、`StockAnalysisDaily`）。

## 和「文件夹版」的区别

| | 安装包 `StockAnalysisSetup.exe` | 文件夹版 `dist\StockAnalysis\` |
| --- | --- | --- |
| 形态 | 一个安装 exe，适合发给别人 | 整个目录拷走也能用 |
| 开始菜单 / 卸载 | 有 | 无 |
| 默认位置 | `%LOCALAPPDATA%\StockAnalysis` | 你把文件夹放在哪就是哪 |
| 是否含历史 PDF | 都不含 | 都不含 |

两者都是同一套程序。发给他人时，优先给安装包。

## 重新制作安装包（维护者）

在项目根目录执行 `python pack.py`：先打出 `dist\StockAnalysis\`，再用 Inno Setup 生成 `dist\installer\StockAnalysisSetup.exe`。脚本为 `installer\StockAnalysis.iss`。
