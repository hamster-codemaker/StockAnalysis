# 成长股分析套件 · 产品说明

## 定位

本工具面向自行做功课的 A 股研究者。它把可量化筛选、法定披露文档、行业政策索引、财务趋势图、技术面信号、自选股日报与**点金术全市场扫描**收成一套可重复运行的工作台，用来降低资料收集与日常对照的成本。程序只落实可复核的步骤；估值高低、增长是否来自新产品新市场、产业趋势是否成立，仍由使用者阅读原文后自行判断。不提供买卖建议，也不代替研判。

统一入口为 `python entry.py` 或打包后的 `StockAnalysis.exe`：无参数打开图形界面，**不出现黑色命令窗口**；`--daily-report` 无窗口生成日报（自选股 + 点金术）；`--watchlist-analyze` 一键分析全部自选股（技术面+基本面+综合分析，不跑点金术）；`--daemon` 登录后只在右下角托盘（不弹主窗、无黑框）。Windows 安装包见 [安装包说明](安装包说明.md)。成长股子命令（`screen` / `download` / `policies` / `update-policies` / `finance` / `run` / `dianjin`）与 `python main.py` 相同；技术面为 `tech`。

## 模块划分

| 模块 | 职责 |
| --- | --- |
| `launcher` | 统一调度、GUI 四页（自选股 / 成长股工具 / 技术面 / 定时任务）、计划任务、托盘、日报 |
| `stock_screener` + `main.py` | 量化筛选、巨潮/东财/国务院政策下载、财务提取与出图 |
| `dianjin` | 点金术 / 点金术extra：全市场估值快照 → 股息+PE → 仅幸存者 MA120 → 命中股技术面/财务 |
| `tech_analysis` | 独立技术面：前复权日线、指标、信号、报告与图；默认输出 `data/tech_analysis/` |
| `app_gui` | 成长股工具面板，嵌在统一 GUI 中；旧入口仍可单独启动 |
| `userdata/` | 用户输入：自选股与开关 |
| `config.yaml` | 筛选阈值、下载范围、网络限速（与 `userdata/settings.yaml` 分离） |

自选股、成长股机械选股、点金术**三套名单分离**：`userdata/watchlist.txt` 是用户自选；`data/screening/` 只放成长股量化扫描；`data/dianjin/` 只放点金术。筛选**不会**把自选股当作股票池。若点金术（或 extra）命中股也在自选股中，只做标注：个股目录名为 `600900_长江电力_自选`（仍以 6 位代码开头，清理按代码匹配），总表 / 名单有「自选」列，日报总览单独列出这些代码。自选股为空时不标注、不报错；自选股章节记「今日无符合」，**点金术仍全市场执行**。点金术与点金术extra 是并列文件夹，标注各自独立。

## 数据源

公开渠道、精确 URL、停用原因与股息率验算见 [数据源与合规](数据源与合规.md)。摘要如下。

只访问免登录公开 HTTP；**不伪造 TLS 指纹**；**不请求**东财 `push2` / `push2his`（其 `robots.txt` 为全站禁止）。巨潮公告、国务院政策、东财 F10 / 数据中心 / 研报列表、腾讯行情、同花顺 F10 分红页。全局限速与失败重试；默认绕过系统代理直连。不登录、不携带密钥、**不解析扫描版 PDF** 冒充结构化财报。财务数字来自东财公开报表接口，与披露定期报告同一口径。

**K 线 / 日线默认腾讯**；成长股全 A 排行腾讯优先、东财数据中心其次。顺序记在 `userdata/source_preference.yaml`（不是密钥，不打进安装包）；旧文件里的 `eastmoney` / `clist` / `sina` 会被忽略。某主源整轮失败且备用成功时对调并写回。

**证券简称本地优先。** 查找顺序：调用方已有名称 → 进程内缓存 → `data/cache/stock_names.json` → `data/docs/<代码>_*` 目录名（去掉 `_自选`）→ 巨潮 `szse_stock.json` → 腾讯行情。查不到返回空串，不阻塞日报。

**日 K 缓存新鲜度。** 当日缓存文件（`data/cache/kline/<代码>_<日期>.json`）按上海时区判定：收盘后（≥15:15）若最后一根 K 仍是昨天、且缓存写于当日收盘前，自动失效重拉，保证收盘后跑出的「指标日」统一为当天。停牌或源延迟时收盘后重拉一次并落盘；周末沿用周五、盘中允许昨收，均不算过期。

点金术三档市盈率仍写入 `pe_dyn` / `pe_static` / `pe_ttm`（门槛不变）：静态与 TTM 来自东财数据中心 `PE_LAR` / `PE_TTM`，动态市盈率由腾讯行情下标 52 补齐。**筛选用股息率是同花顺「股息率TTM」**；快照预填数据中心 `DV_TTM`（与原 clist `f133` 同列；锚点：思维列控 2.43、中油资本 1.50），对已过市盈率关的股票再用 F10 分红表覆盖。**不要用 f183**，**不要用**同花顺 526792（振幅），也**不要用**腾讯字段 64。价格变动时用「DPS / 现价」还原，不要拿跨日百分数硬比。

**MA120：** 公开接口没有现成 MA120。点金术在股息+PE 过滤后，用**腾讯前复权日线**自算，结果缓存在 `data/cache/kline/`；缺均线或根数不足时再补一轮。

## 文档、政策、财务、技术面、点金术、日报、静默更新

**文档。** 按股票写入 `data/docs/<代码>_<名称>/`：招股说明书、全量定期财报、个股/行业研报。增量记录在 `data/manifest.json`。

**政策。** 正文与附件进入中央库 `data/policies/文件库/`，以原文链接全局去重；总清单为 `政策总清单.csv`。个股目录只生成 `政策文件索引.md`（相对路径指向中央库）。刷新范围固定为：① 用户自选股；② 本地已有 `财报/` 或 `研报/` 且其中有文件的股票。筛选 CSV 命中但本地尚无文档的代码**不建空目录**。

**财务。** 提取多期营收、归母/扣非净利、现金流、利润率、ROE 等，计算同比与环比。本地 `财务数据.csv` 最新报告期已覆盖远端最新期时，**不出网硬刷**，直接用本地表出图；仅落后或缺失时才拉全表，并在需要时补最新定期报告 PDF。累计同比图对低基数/极端百分比截断可视轴（CSV 仍保留原值，图上标注「低基数」）。另出**单季拆分图**：Q1=一季报，Q2=半年报−一季报，Q3=三季报−半年报，Q4=年报−三季报；单季同比=历年同季，单季环比=上一自然季。每只股票五张图：营收与净利、利润率与 ROE、经营现金流 vs 净利、累计同比、单季营收与净利。

**技术面。** 对自选股（以及点金术命中股）画最近 **120 个交易日** K 线（不是日历日），叠加 MA8 / MA24 / MA120；分图为布林、MACD、RSI。参数按通达信/同花顺/东财常见默认：BOLL N=20 P=2；MACD 12/26/9；RSI 通达信 RSI1/2/3 = 6/12/24（信号主周期 RSI6）。为让 MA120 在可见窗口内有定义，日线预热约 250 根（`tech_analysis/config.yaml` 的 `warmup_extra_days`）。规则写在报告中。输出分析报告、综合图、`signals.csv`、`日线指标.csv`。近 5 个交易日信号在点金术个股报告中高亮。

**点金术。** 每个交易日对**全部 A 股**（默认剔除 ST/*ST/退市、不含北交所）做一次估值快照，而不是给约五千只股票各拉 120 日 K 线。步骤固定为：① 东财数据中心估值表翻完全市场（收盘、静态/TTM 市盈率、预填股息），动态市盈率用腾讯下标 52 补齐；对明显漏字段的行再用缓存快照补一轮；② 先用股息与三档市盈率过滤，通常剩下几十到几百只；③ **只对幸存者**用腾讯前复权日线算 MA120（不足 120 根不算通过）；缺均线再补一轮；④ 技术面与财务 **只增强最终命中股**，缺文件再补一轮。点金术：股息率 **> 3%**（**只按同花顺股息率TTM**；快照预填 `DV_TTM`），三档 PE 均 **0 < PE < 20**，收盘 **< MA120 × 88%**。点金术extra 是加严子集：同一套 PE，且同一股息 **> 4%**、收盘 **< MA120 × 82%**。缺数、非数字、负 PE 一律不通过。估值快照整体失败时写出空名单并标明错误，**不放宽市盈率规则**。空名单写「今日无符合」，日报继续。点金术 / extra **总表**（md+csv）带最近技术指标：指标日、MA8、MA24、BOLL 位置、MACD、RSI6/12/24、近5日信号，复用命中股已算日线，不另拉行情（「指标日」即该股日线最后一根 K 的日期）。另出**技术信号汇总**（md+csv）：每只命中股一行/一节，列出指标日与已检出信号（均线金叉死叉、MACD、布林、RSI 等），当天没有信号写「今日无信号」；文件放在 `点金术/技术信号汇总.md|.csv` 与 `点金术extra/点金术extra技术信号汇总.md|.csv`，日报再各提一份到日期根目录（带「点金术」前缀，避免撞名）。财务复用 `data/docs` 本地 CSV/图；若该股从未下载（无 `财务数据.csv` 且无财报 PDF），当日才拉公开财报接口并只补**最新一期**定期 PDF，**不下**历史招股书、全量定期报告或研报。输出在 `data/dianjin/YYYYMMDD/点金术/` 与并列的 `data/dianjin/YYYYMMDD/点金术extra/`（extra 有独立总表和个股副本）。已出局股票会从对应文件夹的 `个股/` 按 **6 位代码** 删掉（目录可带 `_自选` 后缀）。日报复制为桌面 `点金术/` 与 `点金术extra/` 两个并列文件夹。`--hist-limit` / `--limit` / `--screen-only` 只给测试用，日报入口不会带这些参数。

**日报。** `daily_update=true` 时，按 `daily_time`（默认 16:00）写入 `report_dir`；空则默认「桌面/日报集」，其下再按日期建子目录，避免铺在桌面根。日报**每天自动分析全部自选股**（技术面 + 基本面 + 综合分析），再跑点金术全市场。日期目录结构：`总览.md`（自选股 / 点金术分节）＋日期根的 `点金术技术信号汇总.md|.csv`、`点金术extra技术信号汇总.md|.csv`＋并列的 `自选股/`、`点金术/`、`点金术extra/` 三个文件夹。`自选股/` 含 `总表.md|.csv`、`技术面汇总.md`、`基本面汇总.md` 与 `个股/<代码>_<名称>/`（内含 `综合分析.md` 及 `技术面/`、`基本面/` 详报）；不再往日期根散写技术面/基本面汇总。总览会单独高亮「点金术中的自选股」。`daily_update=false` 时 `--daily-report` 只打日志、**不写桌面**（`--force` 可强制一次）。副本另存 `data/daily_reports/<日期>/`。

**一键分析。** 界面「自选股」页「分析全部自选股」按钮与 CLI `--watchlist-analyze` 走同一条流水线：对名单每只股票做技术面 + 基本面 + `综合分析.md`，写入固定位置 `data/watchlist/` 与当日 `日报集/<日期>/自选股/`（结构同上）。名单为空写「今日无符合」，不报错；此入口不跑点金术。

**静默更新。** `--daemon` 以托盘图标常驻：登录后不弹主窗口、不弹黑框；需要时从右下角打开主界面。完整日报有两道保障，**都不要求点开托盘**：① Windows 计划任务 `StockAnalysisDaily` 到点运行 `--daily-report`；② 托盘进程内部定时，到点也会生成日报（当日已生成则跳过）。开机若打开了每日更新，可先默默刷技术面。失败只写 `userdata/daemon.log`。新安装默认打开开机自启与每日更新，可在界面或 `settings.yaml` 随时关掉。

## 配置接口

**`userdata/settings.yaml`（每次运行重读；GUI「定时任务」勾选立刻写回）：**

| 键 | 含义 |
| --- | --- |
| `autostart` | 登录后 `--daemon` 托盘；计划任务名 `StockAnalysisAutostart` |
| `daily_update` | 是否生成日报；对应任务 `StockAnalysisDaily` |
| `daily_time` | 日报时刻，默认 `16:00` |
| `report_dir` | 日报根目录；空 = 桌面/日报集 |
| `earnings_season_months` | 财报季月份标注（写入日报说明，不替代「本地已最新则不出网」） |

另有自动维护的 `userdata/source_preference.yaml`：K 线/日线/实时行情的源顺序（默认腾讯优先，不含东财 push2）。程序写回，不必手改。新安装没有此文件时用代码内默认。

进入定时任务页只查询任务状态，**不在主线程**调用 `schtasks`，也不会因进入该页而创建或删除任务；创建/删除仅在开关变更后于后台同步。

**`config.yaml`：** 成长股筛选增速/市值/机构持仓门槛、点金术股息/PE/MA 门槛、财报类型与研报窗口、政策每行业上限、`network.rate_limit_seconds` 与 `use_system_proxy`。技术面参数在 `tech_analysis/config.yaml`（MA8/24/120、MACD 12/26/9、BOLL 20/2、RSI 6/12/24、回看 120 交易日）。

## 边界：不做什么

- 不提供投资建议、目标价或自动交易。
- 不判断估值贵贱、增长故事或产业拐点。
- 不为「筛选命中但本地没有财报/研报」的股票凭空建档。
- 不把自选股、成长股筛选、点金术三套名单混成一份。
- 不为点金术命中股批量下载历史招股书、全量定期报告或研报。
- 不在估值快照失败时改用缺少三档 PE 的表去放宽规则。
- 不在开机时弹出完整界面；不在进入定时任务页时擅自改系统任务。
- 不把日报直接写到桌面根目录。
- 不把扫描版 PDF 解析成财务表。
