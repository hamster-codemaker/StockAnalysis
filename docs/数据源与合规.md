# 数据源与合规

本文记录本程序**实际发出的 HTTP 请求**、为何停用部分站点，以及筛选数字如何与价格波动对齐。不改变任何输出目录、报表栏目或筛选阈值。

## 原则

- 只访问免登录、无 API Key 的公开 HTTP 接口。
- 不伪造浏览器 TLS 指纹（不再使用 `curl_cffi impersonate`）。
- 不调用 `robots.txt` 声明 `Disallow: /` 的东财 `push2` / `push2his` 集群。
- 不登录、不携带 Cookie / Token / hexin-v。
- 全局限速、失败重试、本地缓存；失败时**不放宽**点金术市盈率规则。
- 仅供个人研究。请遵守各站点使用条款，不要把抓取结果用于商业再分发。

### 前复权日线 / MA120

公开接口没有现成 MA120。K 线只走腾讯（旧配置里的东财 push2his、新浪会被丢弃）：

1. `GET https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={sh\|sz}{code},day,,,{limit},qfq`
2. 备用 `GET https://proxy.finance.qq.com/ifzqgtimg/appstock/app/newfqkline/get`

## 已停用的高风险源

| 原请求 | 原因 | 替代 |
| --- | --- | --- |
| `https://push2*.eastmoney.com/api/qt/clist/get` | 该主机 `robots.txt` 为 `User-agent: * / Disallow: /`，且过去用 TLS 指纹伪装才能稳定访问 | 数据中心 `RPT_VALUEANALYSIS_DET` + 腾讯下标 52 |
| `https://push2his*.eastmoney.com/api/qt/stock/kline/get` | 同上 | 腾讯 `fqkline` |
| `curl_cffi impersonate="chrome120"` | 主动规避站点的客户端识别 | 普通 `requests` + 浏览器 UA / 页面 Referer |
| 东财 `stock_individual_info_em`（内部仍打 push2） | 同上 | 腾讯简称 |
| 新浪行情中心 / `hq.sinajs.cn` / 机构持股 | 用户要求去掉对新浪的依赖；分页漏票会导致点金术整只消失 | 动态 PE 用腾讯下标 52；K 线与简称只用腾讯；机构持仓用东财基金持仓 |

同花顺 `bonus.html` 的 `robots.txt` 只禁止 `/admin/`，本程序只读分红实施表，不走问财、不破解 `hexin-v`。

## 股息率如何消除股价波动

名单上的「股息率」是百分数：

```
股息率TTM(%) = 近窗口已实施现金分红每股合计 / 计算用收盘价 × 100
```

现金分红来自同花顺 F10 已实施方案（剔除股利支付率 >200% 的特别分红）。股价每天变，股息率也会变，但**分子 DPS 不变**时应满足：

```
股息率_新 × 价格_新 = 股息率_旧 × 价格_旧 = DPS × 100
```

验收脚本 `tools/validate_outputs.py` 用名单收盘价复算 DPS，再与现场 F10 对照（容差 0.06 个百分点）。不要用跨日名单的百分数直接比，那是价格在动，不是口径错了。

三档市盈率、MA120 折扣、输出目录与 `.md` / `.csv` 栏目**未改**。换源只发生在抓取层。
