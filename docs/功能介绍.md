# 这套工具能帮你干什么

一句话：把「找成长股、把该读的材料攒齐、每天看一眼自选股，再扫一遍高股息折价名单」这件事自动化，你自己负责判断。

## 它能替你做的

**先用数字筛一遍。** 业绩增速够不够、盘子大不大、机构扎堆到什么程度，程序按门槛过一遍，给你一份机械名单，放在筛选结果目录里。贵不贵、故事成不成立，它不管。

**自选股是你的名单。** 和程序筛出来的成长股清单、点金术清单都分开。你盯的那几只写在自选股文件里；下载、财务、政策索引、技术面、日报自选股章节都认这一份。点金术筛选**不拿**这份名单当股票池。如果某只点金术命中股刚好也在自选股里，文件夹会标成 `代码_名称_自选`，总表有「自选」列，日报总览也会点名，方便你一眼看见。自选股空了也不要紧：不标注、不报错，日报写「今日无符合」，点金术照样全市场跑。

**把该读的文件放到手边。** 招股书、年报季报、券商研报，按股票归好类。行业政策另有一份公共库，个股目录里只放索引，避免同一份文件复制十几遍。

**政策只跟你真正在看的股票走。** 自选股，以及你已经存了财报或研报的股票，会更新政策索引。筛选里扫到、本地还没文档的，不会白白建一堆空文件夹。

**财务给你能对照的数和图。** 每只能看到最近一期的营收净利、同比环比、利润率、现金流，还有多期表。本地财报已经是最新一期，就直接用本地出图，不必每次把历史再拉一遍。累计同比图会把低基数撑爆坐标轴的点截掉，避免一张图全被极端百分比占满。另外还有单季拆分：一季就是一季报，二季用半年减一季，三季用三季减半年，四季用年报减三季，方便看各季本身而不是累计口径。一共五张图。

**技术面也不只两句话。** 图上是最近 120 个交易日的 K 线，叠加 MA8 / MA24 / MA120，下面分图是布林（20,2）、MACD（12,26,9）、RSI（通达信 6/12/24）。信号带日期和数值。当天有没有触发，报告里会写明。点金术个股还会标出最近 5 个交易日的信号。

**点金术每天扫全市场，但不傻拉五千根均线。** 先用东财数据中心估值表看静态/TTM 市盈率和预填股息，动态市盈率用腾讯行情补齐，剩下的名字才用腾讯前复权日线算 MA120。公开接口里没有现成的 MA120 字段，只能自己算。过线的叫点金术（股息大于 3%、三种市盈率都小于 20、收盘低于 120 日均线的 88%）；更严的叫点金术extra（股息大于 4%、收盘低于均线的 82%），一定是点金术的子集。缺数据或亏损市盈率直接淘汰。缺均线或财务文件会再补一轮。名单空了就写「今日无符合」，不会把程序弄挂。命中的股票会出总表、名单和每只一份 120 日 K 线技术面+财务；extra 另有独立文件夹和个股副本，方便单独打开。已出局的股票会从当天点金文件夹里按代码删掉（自选标注的目录名带 `_自选` 也不影响）。财务能用本地的就用本地，从来没下过才补最新一期财报，不会为了这份名单把历史招股书全下一遍。

**收盘后有一份能翻的日报。** 不是三张空表：自选股单独一个文件夹，每只都有完整基本面（含单季图）、技术面，外加一份「综合分析」把两侧要点放在一页对照；点金术、点金术extra 是并列的独立文件夹，日期根还各放一份「技术信号汇总」，命中股当天触发了什么信号一页看完，不用逐个点开个股。总览页当目录，并单独列出点金术里出现的自选股。默认放在桌面「日报集」里按日期分文件夹。想换地方，改一项配置即可。关掉每日更新后，定时日报命令只记日志，不会往桌面写东西。

**自选股也能随时一键重跑。** 不等日报：界面点「分析全部自选股」或命令行 `--watchlist-analyze`，同一套技术面+基本面+综合分析写到 `data/watchlist/` 和当天日报的自选股文件夹，不会捎带跑点金术。

**开机可以不打扰你。** 登录后只在右下角托盘待着，没有黑框、也不弹主窗口。要用的时候点托盘图标进去。就算你从不点开，到了设定时刻也会自动写出日报。开关写在配置文件里，界面勾选会立刻保存，下次运行重新读取。双击程序打开界面时同样没有命令行黑框。

## 它对你有什么用

适合已经愿意自己读材料、只是不想每天重复搜集和整理的人。它把「资料在哪、这期财务变了没有、技术面最近出过什么信号」摊开，让你把时间花在阅读和判断上。

## 它不会替你做的

不会告诉你该买还是该卖，不会估一个「合理价格」，也不会把筛选结果或点金术名单偷偷写进自选股。数据来自公开披露和公开行情，失败了记日志，不拿弹窗打断你。
