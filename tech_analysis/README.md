# 自选股技术面分析

独立于主程序的技术指标扫描：只分析你用**文件**提供的自选股，不改 `main.py`、`stock_screener/` 或项目根 `config.yaml`。

## 用法

在项目根目录：

```text
python tech_analysis/main.py
python -m tech_analysis
```

在本目录：

```text
python main.py
```

可选参数：`--config`、`--watchlist`、`-v`。

默认读取本目录 `watchlist.txt`（也可用 `.csv`）。路径相对**本目录**解析，不依赖当前工作目录。

## 自选股格式

- 每行一个 6 位代码
- `#` 开头为注释，空行忽略
- 可写 `代码,名称` 或 `代码 名称`
- CSV 若含表头 `代码,名称` 会自动跳过

示例见 `watchlist.txt`（688308 欧科亿、301500 飞南资源）。

## 配置

编辑 `config.yaml`：回看交易日（默认 120）、MA 8/24、MACD 12/26/9、布林 20/2、RSI 14 与超买/超卖 80/20、背离窗口 60、输出目录等。

行情：腾讯前复权日线。不再请求东财 push2his 或新浪。指标用 pandas/numpy 自算，不安装 talib。

网络：默认绕过 Windows 系统代理直连（与主程序相同思路，代码复制在本目录 `network.py`，**不 import stock_screener**）。限速与失败重试见配置 `network` 段。

## 输出

`output/<代码>_<名称>/`

| 文件 | 内容 |
|------|------|
| `signals.csv` | 每条信号一行：日期、类型、细节、收盘价、相关指标 |
| `分析报告.md` | 各类信号是否出现、最近一次日期、规则说明、最新快照 |
| `技术分析.png` | K 线+MA、布林、MACD、RSI 四图 |
| `日线指标.csv` | 回看区间行情与指标，便于核对 |

另有 `output/信号汇总.md` 与 `output/信号汇总.csv`。

## 信号规则

- **MA 金叉**：当日短均线 > 长均线，且前一日短 ≤ 长。死叉相反。
- **MACD 金叉**：当日 DIF > DEA，且前一日 DIF ≤ DEA。死叉相反。HIST = 2×(DIF−DEA)。
- **MACD 顶背离**：当日收盘达到近 N 日最高（默认 N=60），且为「处于近 N 日最高」的首日；在窗口内、与当日至少相隔 `divergence_min_gap`（默认 5）日取前高。价格未低于前高，但 DIF 或 HIST 低于前高当日。底背离对称。报告中会写明窗口。
- **布林上破**：前一日收盘 ≤ 前一日上轨，且当日收盘 > 当日上轨。下穿对称。中轨为 N 日均线，带宽为倍数 × 总体标准差（ddof=0）。
- **RSI 严重超买/超卖**：当日 RSI 越过阈值（默认 80/20）。标注刚进入或持续，并记录刚离开阈值。

以上仅作量化标记，不构成投资建议。

## 图形界面

独立窗口（不要和成长股文档工具混在一起）：

```text
python tech_analysis/gui.py
```

可选择/编辑自选股文件、运行分析、查看日志、打开 `output` 目录。界面用子进程调用 `main.py`，不导入本目录的分析代码。

## 与主程序的关系

本目录自带入口、配置、清单和输出。不参与成长股筛选或文档下载，互不影响。主项目已包含 akshare / pandas / matplotlib，一般不必再装依赖。
